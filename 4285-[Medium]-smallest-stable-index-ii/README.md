# Smallest Stable Index II

🔗 https://leetcode.com/problems/smallest-stable-index-ii/

## 🧠 Approach
This solution uses two arrays, `max` and `min`, to track the maximum and minimum values from the start and end of the array respectively. It then iterates through the array to find the first index where the difference between the maximum and minimum values is less than or equal to `k`.

## ⏱️ Complexity
- Time: O(n)
- Space: O(n)

- Runtime: 6 ms
