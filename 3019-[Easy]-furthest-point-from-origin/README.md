# Furthest Point From Origin

🔗 https://leetcode.com/problems/furthest-point-from-origin/

## 🧠 Approach
This solution uses a HashMap to count the frequency of 'L' and 'R' moves in the input string. It then replaces all '_' with the more frequent direction, and calculates the final distance from the origin by summing the counts of 'L' and 'R' moves.

## ⏱️ Complexity
- Time: O(n)
- Space: O(n)
