# Generate Parentheses

🔗 https://leetcode.com/problems/generate-parentheses/

## 📘 Problem
Given n pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

## 🧪 Examples
```
Example 1:
  Input:  n = 3
  Output: ["((()))","(()())","(())()","()(())","()()()"]

Example 2:
  Input:  n = 1
  Output: ["()"]
```

## 📐 Constraints
```
1 <= n <= 8
```

## 🧠 Approach
- Identify core logic
- Use proper data structure
- Optimize traversal
- Return result

## ⏱️ Complexity
- Time: O(N)
- Space: O(1)
