# Two Furthest Houses With Different Colors

🔗 https://leetcode.com/problems/two-furthest-houses-with-different-colors/

## 🧠 Approach
The given solution uses a brute force approach by iterating over all pairs of houses and checking if they have different colors. It keeps track of the maximum distance found so far.

## ⏱️ Complexity
- Time: O(n^2)
- Space: O(1)

## 📊 Stats
- Runtime: 2 ms
- Memory: 41.54 MB
