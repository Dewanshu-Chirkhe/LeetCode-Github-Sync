# Matrix Diagonal Sum

🔗 https://leetcode.com/problems/matrix-diagonal-sum/

## 🧠 Approach
- This solution iterates through the matrix, checking each element to see if it's on the main diagonal or the anti-diagonal.
- If an element is on the main diagonal, it's added to the sum.
- If an element is on the anti-diagonal, it's also added to the sum.
- This approach ensures that all diagonal elements are included in the sum.
- The solution has a time complexity of O(n^2) due to the nested loops.

## ⏱️ Complexity
- Time: O(n^2)
- Space: O(1)
