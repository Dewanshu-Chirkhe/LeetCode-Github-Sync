# Find the Degree of Each Vertex

🔗 https://leetcode.com/problems/find-the-degree-of-each-vertex/

## 🧠 Approach
The given solution iterates over each vertex in the graph and counts the number of edges connected to it. This approach is simple and straightforward. It has a time complexity of O(n^2) due to the nested loops. The space complexity is O(n) for storing the degrees of each vertex.

## ⏱️ Complexity
- Time: O(n^2)
- Space: O(n)

- Runtime: 3 ms
