# Traffic Signal Color

🔗 https://leetcode.com/problems/traffic-signal-color/

## 🧠 Approach
- The solution checks the timer value to determine the traffic signal color.
- It uses if-else statements to handle different timer values.
- The timer values are hardcoded, which may not be efficient for large inputs.
- The solution returns "Invalid" for timer values outside the expected range.
- The solution does not handle negative timer values.

## ⏱️ Complexity
- Time: O(1)
- Space: O(1)

- Runtime: 1 ms
