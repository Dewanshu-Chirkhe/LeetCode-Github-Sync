# Flipping an Image

🔗 https://leetcode.com/problems/flipping-an-image/

## 🧠 Approach
The given solution iterates over each row in the image, flipping the elements by considering the mirrored column index. It then inverts the color of each element by checking if it's 1 or 0. This approach ensures that the resulting image is a flipped and inverted version of the original.

## ⏱️ Complexity
- Time: O(n^2)
- Space: O(n^2)
