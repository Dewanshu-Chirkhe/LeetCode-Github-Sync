# Shortest Distance to Target String in a Circular Array

🔗 https://leetcode.com/problems/shortest-distance-to-target-string-in-a-circular-array/

## 🧠 Approach
The given solution iterates through the `words` array to find the target string. It calculates the distance between the current word and the `startIndex` both directly and considering the circular nature of the array. The minimum distance is updated accordingly.

## ⏱️ Complexity
- Time: O(n)
- Space: O(1)
