# Angles of a Triangle

🔗 https://leetcode.com/problems/angles-of-a-triangle/

## 🧠 Approach
This solution uses the Law of Cosines to calculate the internal angles of a triangle. It first checks if the given sides can form a valid triangle. If they can, it calculates the angles using the Law of Cosines formula and returns them in ascending order.

## ⏱️ Complexity
- Time: O(1)
- Space: O(1)
