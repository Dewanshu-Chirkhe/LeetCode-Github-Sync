# Distribute Candies

🔗 https://leetcode.com/problems/distribute-candies/

## 🧠 Approach
We use a HashSet to store unique candy types. Then, we calculate the minimum between the number of unique types and half of the total candies. This approach ensures we distribute candies evenly.

## ⏱️ Complexity
- Time: O(n)
- Space: O(n)
