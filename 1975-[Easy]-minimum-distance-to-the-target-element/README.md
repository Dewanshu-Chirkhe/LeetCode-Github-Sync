# Minimum Distance to the Target Element

🔗 https://leetcode.com/problems/minimum-distance-to-the-target-element/

## 🧠 Approach
This solution iterates through the array to find the target element. It keeps track of the minimum difference between the target's index and the start index. Once the target is found, it returns the minimum difference.

## ⏱️ Complexity
- Time: O(n)
- Space: O(1)
