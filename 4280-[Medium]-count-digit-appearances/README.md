# Count Digit Appearances

🔗 https://leetcode.com/problems/count-digit-appearances/

## 🧠 Approach
This solution iterates through each element in the array, and for each element, it counts the occurrences of the given digit by continuously dividing the number by 10 and checking the remainder.

## ⏱️ Complexity
- Time: O(n*m), where n is the length of the array and m is the maximum number of digits in the array elements.
- Space: O(1)

## 📊 Stats
- Runtime: 4 ms
