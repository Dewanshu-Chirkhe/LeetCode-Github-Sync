# Mirror Distance of an Integer

🔗 https://leetcode.com/problems/mirror-distance-of-an-integer/

## 🧠 Approach
The given solution uses a two-pointer approach to calculate the mirror distance of an integer. It first reverses the integer using a while loop and then calculates the absolute difference between the original and reversed integers.

## ⏱️ Complexity
- Time: O(log(n))
- Space: O(1)
