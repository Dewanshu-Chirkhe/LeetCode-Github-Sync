# Multi Source Flood Fill

🔗 https://leetcode.com/problems/multi-source-flood-fill/

## 🧠 Approach
This solution uses a breadth-first search (BFS) approach to flood fill the grid. It maintains a queue of cells to visit and updates the grid and time matrix accordingly. The BFS traversal is performed in a way that it prioritizes cells with the same time value and a higher color value.

## ⏱️ Complexity
- Time: O(n * m)
- Space: O(n * m)

## 📊 Stats
- Runtime: 66 ms
